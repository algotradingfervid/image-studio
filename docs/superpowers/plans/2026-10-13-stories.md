# Stories (brief → consistent video) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Stories tab on Create (beside Image and Video) that turns a prompt + 1–2 saved characters into a planned shot list (local Qwen via LM Studio), renders each shot as an H3 Character job, lets the owner Approve / Reroll / Edit each shot, and stitches the approved shots into one MP4 in the gallery.

**Architecture:** A new Rust module `app/src-tauri/src/stories/` (store, validator, compiler, planner client, render, assemble) on top of the existing job queue (`jobs::generate_video`), DB (`db.rs` migration 4) and references store. The worker gains an optional first frame for `h3ref` (`MiniMaxH3AddGuide` at frame 0) for "continues previous" shots. The UI adds `"stories"` to `CreateMode`: a left panel (story picker, cast, brief) and a right workspace (shot list, takes, assemble) in place of the gallery.

**Tech Stack:** Rust (Tauri 2, rusqlite, reqwest 0.12, tokio, wiremock for tests), React + TypeScript (Vite), Python worker (pytest), ffmpeg 8.1 (Homebrew) on the Mac, LM Studio OpenAI-compatible server.

**Spec:** `docs/superpowers/specs/2026-10-13-stories-design.md` (read it first; this plan argues from it).

## Global Constraints

- Shot duration 5–15 s; ≤ 2 characters per shot; dialogue ≤ 2.5 words/s; total within ±15 % of target; ≤ 6 reference images per shot (`h3ref` `maxReferences` 4 → 6).
- Aspect → resolution: `16:9` → `1344x768`, `9:16` → `768x1344`, `1:1` → `768x768`. Video model `h3ref`, fps 24, audio on.
- Planner endpoint default `http://localhost:1234/v1`, default model `qwen3.8-27b-uncensored-optiq` (fallback: first listed model); temperature 0.6; `response_format` `json_schema`; `chat_template_kwargs: {"enable_thinking": false}`; strip `<think>…</think>`; ≤ 3 attempts.
- Adults only: character form requires "adult" tick; validator rejects under-18 terms; planner prompt states all characters are adults.
- Consent: `real_person` characters need the consent tick; unticked → cannot plan or render.
- The LLM never writes H3 prompt text; `stories/compile.rs` does.
- v1: general destination only (no vault stories); "AI-generated" label is MP4 metadata only (`comment=AI-generated`), no burn-in (installed ffmpeg has no `drawtext`).
- ffmpeg lookup order: `/opt/homebrew/bin/ffmpeg`, `/usr/local/bin/ffmpeg`, `ffmpeg` on PATH. Missing → error "Install ffmpeg (brew install ffmpeg)".
- Loudness `loudnorm=I=-14:TP=-1.5:LRA=11`; output H.264 crf 18 + AAC 48 kHz stereo.
- Story takes are `images` rows with `shot_id` set and never appear in the normal gallery; the assembled result has `story_id` set, `shot_id` NULL, and does appear.
- UI copy, styles and components follow the existing app (panel/section classes, `btn` variants, `useToast`, `gpu.confirmStart`); layouts work down to ~800 px wide.
- Never start a paid GPU without the owner's confirmation (`gpu.confirmStart` in the UI; the owner confirms the real runs in Task 15).

## Review Focus

1. **Planner returns junk** (prose, a `<think>` block, JSON wrapped in ```` ``` ````, wrong character names): expect the client to strip/parse what it can, map names case-insensitively, and after 3 failed attempts still save the best shot list with its issues shown — never crash or lose the brief. → Task 6 tests `parses_fenced_and_think_wrapped_json`, `unknown_character_name_becomes_issue`.
2. **LM Studio not running / model not loaded:** expect one clear message naming LM Studio and how to start it, not a reqwest error string. → Task 6 test `unreachable_server_gives_lm_studio_hint`.
3. **Editing a character after takes exist** (rename, delete, remove an image): expect existing takes to stay playable; deleting a character used by a story is refused with a message naming the story. → Task 3 test `delete_character_in_use_is_refused`.
4. **"Continues" shot whose previous shot has no approved take or whose take file is gone:** expect a clear "Approve shot N first" error, not a panic or an ffmpeg error. → Task 8 test `continues_shot_requires_approved_previous`.
5. **Story takes leaking into the gallery** (live `job-update` events and `list_images`): expect takes only inside the story, the assembled video in the gallery. → Task 2 test `list_images_hides_story_takes` and Task 12 step filtering `job-update` images by `shotId`.

use super::{Character, Issue, Shot, Story};

pub const MIN_SHOT_S: u32 = 5;
pub const MAX_SHOT_S: u32 = 15;
pub const MAX_CAST_PER_SHOT: usize = 2;
pub const WORDS_PER_S: f64 = 2.5;
pub const TOTAL_TOLERANCE: f64 = 0.15;
pub const MAX_REFS_PER_SHOT: usize = 6;

const MINOR_TERMS: &[&str] = &[
    "child", "children", "kid", "kids", "minor", "minors", "teen", "teens", "teenage", "teenager",
    "schoolgirl", "schoolboy", "underage", "preteen", "toddler", "infant", "baby", "loli", "shota",
];

fn words(text: &str) -> Vec<String> {
    text.to_lowercase().split(|c: char| !c.is_alphanumeric()).filter(|w| !w.is_empty()).map(String::from).collect()
}

/// True when `text` describes someone under 18 (term list, or "N years old" / "N-year-old" / "N yo" with N < 18).
pub fn mentions_minor(text: &str) -> bool {
    let w = words(text);
    if w.iter().any(|x| MINOR_TERMS.contains(&x.as_str())) {
        return true;
    }
    w.windows(2).any(|p| {
        p[0].parse::<u32>().is_ok_and(|n| n < 18) && matches!(p[1].as_str(), "year" | "years" | "yo" | "yr" | "yrs")
    })
}

pub fn validate(story: &Story, shots: &[Shot], cast: &[Character]) -> Vec<Issue> {
    let mut out = Vec::new();
    let name = |id: &str| cast.iter().find(|c| c.id == id).map(|c| c.name.clone()).unwrap_or_else(|| id.to_string());
    let story_issue = |out: &mut Vec<Issue>, m: String| out.push(Issue { shot: None, message: m });
    for c in cast {
        if !c.adult {
            story_issue(&mut out, format!("{} is not confirmed as an adult (18+)", c.name));
        }
        if c.source == "real_person" && !c.consent {
            story_issue(&mut out, format!("{} is a real person without a consent tick", c.name));
        }
        if mentions_minor(&c.description) {
            story_issue(&mut out, format!("{}'s description must describe an adult; stories use adults only", c.name));
        }
    }
    if mentions_minor(&story.brief) || mentions_minor(&story.style) {
        story_issue(&mut out, "The brief must describe adults only".into());
    }
    if shots.is_empty() {
        story_issue(&mut out, "The story has no shots".into());
        return out;
    }
    let total: u32 = shots.iter().map(|s| s.duration_s).sum();
    let (lo, hi) = (story.target_s as f64 * (1.0 - TOTAL_TOLERANCE), story.target_s as f64 * (1.0 + TOTAL_TOLERANCE));
    if (total as f64) < lo || (total as f64) > hi {
        story_issue(&mut out, format!("Shots add up to {total} s; the target is {} s (±15 %)", story.target_s));
    }
    for (i, s) in shots.iter().enumerate() {
        let n = Some(s.position);
        let mut push = |m: String| out.push(Issue { shot: n, message: m });
        if !(MIN_SHOT_S..=MAX_SHOT_S).contains(&s.duration_s) {
            push(format!("Duration {} s is outside 5–15 s", s.duration_s));
        }
        if s.characters.len() > MAX_CAST_PER_SHOT {
            push(format!("{} characters; at most 2 per shot", s.characters.len()));
        }
        for c in &s.characters {
            if !story.cast.contains(c) {
                push(format!("{} is not in the cast", name(c)));
            }
        }
        let words_total: usize = s.dialogue.iter().map(|d| words(&d.line).len()).sum();
        let max_words = (WORDS_PER_S * s.duration_s as f64).floor() as usize;
        if words_total > max_words {
            push(format!("Dialogue has {words_total} words; at most {max_words} fit in {} s", s.duration_s));
        }
        for d in &s.dialogue {
            if !s.characters.contains(&d.speaker) {
                push(format!("{} speaks but is not in this shot", name(&d.speaker)));
            }
        }
        if [&s.action, &s.setting, &s.camera].iter().any(|t| mentions_minor(t)) || s.dialogue.iter().any(|d| mentions_minor(&d.line)) {
            push("Stories use adults only; remove the reference to a minor".into());
        }
        if s.continuity == "continues" {
            if i == 0 {
                push("The first shot cannot continue a previous shot".into());
            } else if !s.characters.iter().any(|c| shots[i - 1].characters.contains(c)) {
                push("Continues the previous shot but shares no character with it".into());
            }
        }
        let refs: usize = s.characters.iter().filter_map(|id| cast.iter().find(|c| &c.id == id)).map(|c| c.ref_ids.len()).sum();
        if refs > MAX_REFS_PER_SHOT {
            push(format!("{refs} reference images; at most 6 reference images per shot"));
        }
    }
    out
}

```rust
use super::{Character, Shot, Story};

pub const MAX_PROMPT_CHARS: usize = 7000;

pub struct Compiled { pub prompt: String, pub ref_ids: Vec<String> }

fn trim_end_dot(s: &str) -> &str { s.trim().trim_end_matches('.') }

pub fn compile_shot(story: &Story, shot: &Shot, cast: &[Character]) -> Result<Compiled, String> {
    // Characters of this shot in cast order (fixed numbering across shots).
    let chars: Vec<&Character> = story.cast.iter()
        .filter(|id| shot.characters.contains(id))
        .filter_map(|id| cast.iter().find(|c| &c.id == id))
        .collect();
    let mut lines = vec!["ROLES:".to_string()];
    let mut ref_ids = Vec::new();
    for c in &chars {
        let first = ref_ids.len() + 1;
        ref_ids.extend(c.ref_ids.iter().cloned());
        let tags: Vec<String> = (first..=ref_ids.len()).map(|n| format!("<Picture {n}>")).collect();
        let (verb, these) = if tags.len() == 1 { ("is", "this picture") } else { ("are", "these pictures") };
        lines.push(format!("{} {verb} {}: {}. Keep {}'s face, hair, body and clothing identical to {these}.",
            tags.join(", "), c.name, trim_end_dot(&c.description), c.name));
    }
    let name = |id: &str| cast.iter().find(|c| c.id == id).map(|c| c.name.as_str()).unwrap_or(id);
    lines.push(format!("SHOT ({} s, {}, {}): {}.", shot.duration_s, story.aspect, shot.camera.trim(), trim_end_dot(&shot.setting)));
    lines.push(shot.action.trim().to_string());
    for d in &shot.dialogue {
        lines.push(format!("{} says: \"{}\"", name(&d.speaker), d.line.trim()));
    }
    let look = if story.style.trim().is_empty() { "natural cinematic look" } else { trim_end_dot(&story.style) };
    lines.push(format!("LOOK: {look}."));
    lines.push("SOUND: natural ambient sound of the setting. Dialogue is spoken aloud and lip-synced to the speaker.".into());
    lines.push("LIMITS: Hold identity and clothing from the pictures. No subtitles, no on-screen text, no watermark, no extra people, no face morphing.".into());
    let prompt = lines.join("\n");
    if prompt.chars().count() > MAX_PROMPT_CHARS {
        return Err(format!("Shot {} compiles to {} characters; H3 takes at most 7,000", shot.position, prompt.chars().count()));
    }
    Ok(Compiled { prompt, ref_ids })
}

pub fn system_prompt(story: &Story, cast: &[Character]) -> String {

/// Extracts the JSON object from a model reply: drops `<think>…</think>`, code fences and prose around it.
pub fn parse_reply(content: &str) -> Result<Value, String> {
    let mut text = content.to_string();
    while let (Some(a), Some(b)) = (text.find("<think>"), text.find("</think>")) {
        if b < a { break; }
        text.replace_range(a..b + "</think>".len(), "");
    }
    let (start, end) = (text.find('{'), text.rfind('}'));
    match (start, end) {
        (Some(a), Some(b)) if b > a => serde_json::from_str(&text[a..=b]).map_err(|e| format!("The planner's reply is not valid JSON ({e})")),
        _ => Err("The planner's reply contains no JSON object".into()),
    }
}

fn to_shots(v: &Value, story: &Story, cast: &[Character], issues: &mut Vec<Issue>) -> Vec<Shot> {
    let id_of = |name: &str, issues: &mut Vec<Issue>, pos: u32| -> String {
        match cast.iter().find(|c| c.name.eq_ignore_ascii_case(name.trim())) {
            Some(c) => c.id.clone(),
            None => { issues.push(Issue { shot: Some(pos), message: format!("{} is not in the cast", name.trim()) }); name.trim().to_string() }
        }
    };
    let s = |x: &Value, k: &str| x.get(k).and_then(Value::as_str).unwrap_or("").trim().to_string();
    v.get("shots").and_then(Value::as_array).cloned().unwrap_or_default().iter().enumerate().map(|(i, x)| {
        let pos = i as u32 + 1;
        let characters = x.get("characters").and_then(Value::as_array).cloned().unwrap_or_default()
            .iter().filter_map(Value::as_str).map(|n| id_of(n, issues, pos)).collect();
        let dialogue = x.get("dialogue").and_then(Value::as_array).cloned().unwrap_or_default().iter()
            .map(|d| DialogueLine { speaker: id_of(&s(d, "speaker"), issues, pos), line: s(d, "line") })
            .filter(|d| !d.line.is_empty()).collect();
        let continuity = if s(x, "continuity") == "continues" { "continues" } else { "cut" };
        Shot { id: uuid::Uuid::new_v4().to_string(), story_id: story.id.clone(), position: pos,
            duration_s: x.get("duration_s").and_then(Value::as_u64).unwrap_or(0) as u32,
            characters, setting: s(x, "setting"), camera: s(x, "camera"), action: s(x, "action"),
            dialogue, continuity: continuity.into(), approved_take_id: None }
    }).collect()
}

async fn chat(http: &reqwest::Client, base_url: &str, body: &Value) -> Result<Result<String, String>, String> {
    // Outer Err = transport failure (LM Studio not reachable); inner Err = HTTP error body.
    let resp = http.post(format!("{base_url}/chat/completions")).json(body).send().await
        .map_err(|_| LM_STUDIO_HINT.to_string())?;
    let status = resp.status().as_u16();
    let v: Value = resp.json().await.unwrap_or(Value::Null);
    if status >= 400 {
        return Ok(Err(v.to_string()));
    }
    Ok(v.pointer("/choices/0/message/content").and_then(Value::as_str).map(String::from)
        .ok_or_else(|| "The planner returned no message".to_string()))
}

pub async fn plan(base_url: &str, model: &str, story: &Story, cast: &[Character]) -> Result<PlanOutcome, String> {
    let http = reqwest::Client::builder().timeout(TIMEOUT).build().map_err(|e| e.to_string())?;
    let mut messages = vec![json!({"role": "system", "content": system_prompt(story, cast)}),
                            json!({"role": "user", "content": user_prompt(story)})];
    let mut structured = true;
    let mut best: Option<PlanOutcome> = None;
    let mut attempt = 0;
    while attempt < MAX_ATTEMPTS {
        attempt += 1;
        let mut body = json!({"model": model, "messages": messages, "temperature": TEMPERATURE,
            "chat_template_kwargs": {"enable_thinking": false}});
        if structured {
            body["response_format"] = json!({"type": "json_schema", "json_schema": {"name": "story_plan", "strict": true, "schema": schema()}});
        }
        let content = match chat(&http, base_url, &body).await? {
            Ok(c) => c,
            Err(err) if structured && err.contains("response_format") => { structured = false; attempt -= 1; continue; }
            Err(err) => return Err(format!("The local LLM returned an error: {err}")),
        };
        let mut issues = Vec::new();
        let (title, logline, shots) = match parse_reply(&content) {
            Ok(v) => {
                let shots = to_shots(&v, story, cast, &mut issues);
                (v.get("title").and_then(Value::as_str).unwrap_or("").to_string(),
                 v.get("logline").and_then(Value::as_str).unwrap_or("").to_string(), shots)
            }
            Err(e) => { issues.push(Issue { shot: None, message: e }); (String::new(), String::new(), Vec::new()) }
        };
        issues.extend(validate(story, &shots, cast));
        let outcome = PlanOutcome { title, logline, shots, issues, attempts: attempt };
        if outcome.issues.is_empty() { return Ok(outcome); }
        let errors: Vec<String> = outcome.issues.iter().map(|i| match i.shot {
            Some(n) => format!("Shot {n}: {}", i.message), None => i.message.clone() }).collect();
        messages.push(json!({"role": "assistant", "content": content}));
        messages.push(json!({"role": "user", "content": format!("Fix these problems and reply with the full corrected JSON only:\n{}", errors.join("\n"))}));
        if best.as_ref().map_or(true, |b| outcome.issues.len() <= b.issues.len() && !outcome.shots.is_empty()) {
            best = Some(outcome);
        }
    }
    let mut out = best.ok_or("The planner produced nothing usable")?;
    out.attempts = attempt;
    Ok(out)
}

        .map(|_| PathBuf::from("ffmpeg")).ok_or_else(|| FFMPEG_MISSING.to_string())
}

fn run(ffmpeg: &Path, args: &[String]) -> Result<(), String> {
    let out = Command::new(ffmpeg).args(args).output().map_err(|e| format!("Could not run ffmpeg: {e}"))?;
    if out.status.success() { return Ok(()); }
    let err = String::from_utf8_lossy(&out.stderr);
    let tail: Vec<&str> = err.lines().rev().take(3).collect();
    Err(format!("ffmpeg failed: {}", tail.into_iter().rev().collect::<Vec<_>>().join(" / ")))
}

fn s(p: &Path) -> String { p.to_string_lossy().into_owned() }

pub fn last_frame_png(ffmpeg: &Path, video: &Path, out_png: &Path) -> Result<(), String> {
    run(ffmpeg, &["-hide_banner".into(), "-loglevel".into(), "error".into(), "-sseof".into(), "-0.1".into(),
        "-i".into(), s(video), "-frames:v".into(), "1".into(), "-update".into(), "1".into(), "-y".into(), s(out_png)])
}

pub fn first_frame_jpg(ffmpeg: &Path, video: &Path, out_jpg: &Path) -> Result<(), String> {
    run(ffmpeg, &["-hide_banner".into(), "-loglevel".into(), "error".into(), "-i".into(), s(video),
        "-frames:v".into(), "1".into(), "-q:v".into(), "3".into(), "-y".into(), s(out_jpg)])
}

pub fn assemble_args(inputs: &[PathBuf], out: &Path) -> Vec<String> {
    let mut a: Vec<String> = vec!["-hide_banner".into(), "-loglevel".into(), "error".into()];
    for i in inputs { a.push("-i".into()); a.push(s(i)); }
    let streams: String = (0..inputs.len()).map(|i| format!("[{i}:v][{i}:a]")).collect();
    let filter = format!("{streams}concat=n={}:v=1:a=1[v][a0];[a0]loudnorm=I=-14:TP=-1.5:LRA=11,aresample=48000[a]", inputs.len());
    for x in ["-filter_complex", &filter, "-map", "[v]", "-map", "[a]", "-c:v", "libx264", "-crf", "18",
              "-pix_fmt", "yuv420p", "-c:a", "aac", "-ar", "48000", "-ac", "2",
              "-metadata", "comment=AI-generated", "-movflags", "+faststart", "-y"] {
        a.push(x.to_string());
    }
    a.push(s(out));
    a
}

pub fn assemble(ffmpeg: &Path, inputs: &[PathBuf], out: &Path) -> Result<(), String> {
    if inputs.is_empty() { return Err("Nothing to assemble".into()); }
    run(ffmpeg, &assemble_args(inputs, out))
}

    ids.iter().map(|id| store::get_character(&db, id)?.ok_or_else(|| "A cast character no longer exists".to_string())).collect()

pub fn story_view(core: &Core, story_id: &str) -> Result<StoryView, String> {
    let (story, shots, takes) = {
        let db = core.db.lock().unwrap();
        let story = store::get_story(&db, story_id)?.ok_or("That story no longer exists")?;
        (story, store::list_shots(&db, story_id)?, db.list_takes(story_id)?)
    };
    let cast = cast_of(core, &story.cast)?;
    let mut issues = if shots.is_empty() { Vec::new() } else { validate(&story, &shots, &cast) };
    for s in &shots {
        if let Err(e) = compile_shot(&story, s, &cast) { issues.push(Issue { shot: Some(s.position), message: e }); }
    }
    Ok(StoryView { story, cast, shots, takes, issues })
}

fn take_path(core: &Core, take_id: &str) -> Result<std::path::PathBuf, String> {
    let rec = core.db.lock().unwrap().get_image(take_id)?.ok_or("The approved take's video is missing")?;
    let p = std::path::PathBuf::from(&rec.path);
    if p.is_file() { Ok(p) } else { Err("The approved take's video file is missing".into()) }
}

pub fn render_shot(core: &Arc<Core>, shot_id: &str) -> Result<String, String> {
    let shot = {
        let db = core.db.lock().unwrap();
        store::get_shot(&db, shot_id)?.ok_or("That shot no longer exists")?
    };
    let view = story_view(core, &shot.story_id)?;
    if let Some(i) = view.issues.first() {
        return Err(match i.shot { Some(n) => format!("Shot {n}: {}", i.message), None => i.message.clone() });
    }
    let compiled = compile_shot(&view.story, &shot, &view.cast)?;
    if compiled.ref_ids.is_empty() {
        return Err(format!("Shot {} has no character with reference images", shot.position));
    }
    let mut init_image_id = None;
    if shot.continuity == "continues" {
        let prev = view.shots.iter().find(|s| s.position + 1 == shot.position).ok_or("The previous shot is missing")?;
        let take = prev.approved_take_id.as_deref().ok_or_else(|| format!("Approve shot {} first", prev.position))?;
        let ff = ffmpeg::find_ffmpeg()?;
        let dir = core.cfg.data_dir.join("stories-tmp");
        std::fs::create_dir_all(&dir).map_err(|e| e.to_string())?;
        let png = dir.join(format!("{}.png", uuid::Uuid::new_v4()));
        ffmpeg::last_frame_png(&ff, &take_path(core, take)?, &png)?;
        let bytes = std::fs::read(&png).map_err(|e| e.to_string());
        let _ = std::fs::remove_file(&png);
        init_image_id = Some(crate::references::import_bytes(&core.cfg.references_dir(), &bytes?)?.ref_id);
    }
    let req = VideoRequest {
        model: VIDEO_MODEL.into(), prompt: compiled.prompt, reference_ids: compiled.ref_ids, init_image_id,
        duration_s: shot.duration_s as f64, fps: FPS, resolution: resolution_for(&view.story.aspect)?.into(),
        audio: true, destination: Destination::General,
        story_take: Some((shot.story_id.clone(), shot.id.clone())), ..Default::default()
    };
    jobs::generate_video(core, req)
}

pub fn render_story(core: &Arc<Core>, story_id: &str) -> Result<Vec<(String, String)>, String> {
    let view = story_view(core, story_id)?;
    let mut out = Vec::new();
    for s in &view.shots {
        let has_takes = view.takes.iter().any(|t| t.shot_id.as_deref() == Some(s.id.as_str()));
        let prev_ok = s.continuity == "cut" || view.shots.iter().any(|p| p.position + 1 == s.position && p.approved_take_id.is_some());
        if !has_takes && prev_ok {
            out.push((s.id.clone(), render_shot(core, &s.id)?));
        }
    }
    Ok(out)
}

pub fn approve_take(core: &Arc<Core>, shot_id: &str, take_id: &str) -> Result<Option<(String, String)>, String> {
    let shot = {
        let db = core.db.lock().unwrap();
        let take = db.get_image(take_id)?.ok_or("That take no longer exists")?;
        if take.shot_id.as_deref() != Some(shot_id) { return Err("That take belongs to another shot".into()); }
        store::set_approved(&db, shot_id, Some(take_id))?;
        store::get_shot(&db, shot_id)?.ok_or("That shot no longer exists")?
    };
    let view = story_view(core, &shot.story_id)?;
    let Some(next) = view.shots.iter().find(|s| s.position == shot.position + 1) else { return Ok(None) };
    let next_has_takes = view.takes.iter().any(|t| t.shot_id.as_deref() == Some(next.id.as_str()));
    if next.continuity == "continues" && !next_has_takes {
        return Ok(Some((next.id.clone(), render_shot(core, &next.id)?)));
    }
    Ok(None)
}

pub fn assemble_story(core: &Core, story_id: &str) -> Result<ImageRecord, String> {
    let view = story_view(core, story_id)?;
    let mut inputs = Vec::new();
    for s in &view.shots {
        let take = s.approved_take_id.as_deref().ok_or_else(|| format!("Approve a take for shot {} first", s.position))?;
        inputs.push(take_path(core, take)?);
    }
    let ff = ffmpeg::find_ffmpeg()?;
    let id = uuid::Uuid::new_v4().to_string();
    let out = core.cfg.videos_dir().join(format!("{id}.mp4"));
    ffmpeg::assemble(&ff, &inputs, &out)?;
    let poster = core.cfg.videos_dir().join(format!("{id}.jpg"));
    ffmpeg::first_frame_jpg(&ff, &out, &poster)?;
    let first = core.db.lock().unwrap().get_image(view.shots[0].approved_take_id.as_deref().unwrap())?.ok_or("take missing")?;
    let rec = ImageRecord {
        id: id.clone(), path: out.to_string_lossy().into(), model: VIDEO_MODEL.into(),
        prompt: format!("Story: {}", if view.story.title.is_empty() { &view.story.brief } else { &view.story.title }),
        negative_prompt: String::new(), aspect_ratio: first.aspect_ratio.clone(), width: first.width, height: first.height,
        seed: 0, steps: 0, cfg: 0.0, references: vec![], loras: vec![], created_at: chrono::Utc::now().to_rfc3339(),
        duration_ms: None, runpod: Default::default(), init_image: None, denoise: None, kind: KIND_VIDEO.into(),
        duration_s: Some(view.shots.iter().map(|s| s.duration_s as f64).sum()), fps: Some(FPS), has_audio: Some(true),
        poster_path: Some(poster.to_string_lossy().into()), vault: false, thumb_path: None,
        story_id: Some(story_id.into()), shot_id: None,
    };
    let sidecar = serde_json::json!({"story": view.story, "shots": view.shots.iter().map(|s| {
        let t = view.takes.iter().find(|t| Some(t.id.as_str()) == s.approved_take_id.as_deref());
        serde_json::json!({"position": s.position, "takeId": s.approved_take_id, "seed": t.map(|t| t.seed), "prompt": t.map(|t| &t.prompt)})
    }).collect::<Vec<_>>()});
    {
        let db = core.db.lock().unwrap();
        if let Some(old) = view.story.result_image_id.as_deref() {
            if let Ok(Some(o)) = db.get_image(old) {
                let _ = std::fs::remove_file(&o.path);
                if let Some(p) = &o.poster_path { let _ = std::fs::remove_file(p); }
                db.delete_image(old)?;
            }
        }
        db.insert_image(&rec)?;
        store::set_result(&db, story_id, &id, &sidecar.to_string())?;
    }
    Ok(rec)
}
```
